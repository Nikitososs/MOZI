СИСТЕМА СРАВНЕНИЙ:
Выдвинута гипотеза соответствия частых букв русского языка символам шифр-текста:
  E(о) = з  =>  (14 * a + b) ≡ 7 (mod 32)
  E(е) = ф  =>  ( 5 * a + b) ≡ 20 (mod 32)

Решение системы:
  Вычитание второго уравнения из первого:
  (14 - 5) * a ≡ (7 - 20) (mod 32)  =>  9 * a ≡ -13 ≡ 19 (mod 32)
  НОД(9, 32) = 1, расширенный алгоритм Евклида дает коэф. Безу u = -7 => 9^(-1) ≡ 25 (mod 32)
  a = (19 * 25) mod 32 = 475 mod 32 = 27
  b = (20 - 5 * 27) mod 32 = (20 - 135) mod 32 = -115 mod 32 = 13

ВЕРНЫЙ КЛЮЧ: a = 27, b = 13
Обратный элемент к ключу a: a^(-1) = 19 (mod 32)
