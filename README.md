## Установка и настройка окружения

1. **Создание виртуального окружения (если создается заново):**
   ```powershell
   python -m venv .venv
   ```

2. **Активация виртуального окружения:**
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. **Установка зависимостей:**
   ```powershell
   pip install -r requirements.txt
   ```

## Запуск тестов (pytest)

Все тесты переведены на фреймворк `pytest`, параметризованы и используют фикстуры из `conftest.py`.

Запуск всех тестов из корня репозитория:
```powershell
pytest
```
или без активации окружения напрямую через venv:
```powershell
.\.venv\Scripts\pytest
```

## Запуск лабораторных работ

### Лабораторная работа № 1: Шифр Цезаря

Запуск интерактивного консольного приложения:
```powershell
python lab_1/main.py
```
или через виртуальное окружение:
```powershell
.\.venv\Scripts\python lab_1/main.py
```

**Пункты меню:**
1. **Шифрование текста** (п. 2.1) — ввод текста и ключа $k \in [1; 31]$, сохранение в `outputs/encrypted.txt`.
2. **Расшифрование текста по ключу** (п. 2.2) — сохранение в `outputs/decrypted.txt`.
3. **Полный перебор всех 31 ключей** (п. 2.2) — сохранение таблицы всех вариантов в `outputs/bruteforce_variants.txt`.
4. **Выполнение задания по варианту** (п. 2.3) — криптоанализ цитаты, определение истинного ключа, автора и произведения, зашифрование фамилии и названия тем же ключом; сохранение в `outputs/variant_1_solution.txt`.
