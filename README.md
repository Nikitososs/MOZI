## Запуск лабораторных работ

### Лабораторная работа № 1: Шифр Цезаря

Запуск интерактивного консольного приложения:
```powershell
python lab_1/main.py
```

**Пункты меню:**
1. **Зашифровать текст** — ввод текста (с клавиатуры или из файла) и ключа $k \in [1; m-1]$, сохранение в `outputs/encrypted.txt`.
2. **Расшифровать текст по ключу** — ввод шифр-текста (с клавиатуры или из файла), сохранение в `outputs/decrypted.txt`.
3. **Взломать шифр (полный перебор)** — ввод шифр-текста (с клавиатуры или из файла), перебор всех возможных ключей для текущего алфавита, сохранение в `outputs/bruteforce_variants.txt`.
4. **Выполнить задание по варианту** — криптоанализ цитаты, нахождение ключа, автора и произведения; сохранение в `outputs/variant_16_solution.txt`.
5. **Сменить алфавит** — переключение между встроенными пресетами (`ru`, `en`) или регистрация собственного алфавита произвольной мощности $m$.
0. **Выход**.

### Лабораторная работа № 2: Криптоанализ аффинного шифра (Вариант 16)

Запуск интерактивного консольного приложения:
```powershell
python lab_2/main.py
```

**Пункты меню:**
1. **Зашифровать текст** — посимвольное линейное преобразование $y = (ax + b) \bmod m$ по ключу $(a, b)$, где $\gcd(a, m) = 1$.
2. **Расшифровать текст по ключу** — обратное преобразование $x = a^{-1}(y - b) \bmod m$.
3. **Криптоанализ** — частотный анализ шифр-текста, выдвижение гипотез о соответствии частых букв, решение систем сравнений и автоматический подбор ключа.
4. **Выполнить задание по варианту (Вариант 16)** — частотный анализ перехваченного текста, решение системы сравнений, нахождение ключа $(a, b) = (27, 13)$, расшифрование текста (А. С. Пушкин, «Няне»), сохранение в `outputs/variant_16_solution.txt` и `outputs/variant_16_bruteforce.txt`.
5. **Математический аппарат**:
   - Расширенный алгоритм Евклида: вход $(a, b) \to$ выход $d = \gcd(a, b)$, коэффициенты Безу $u, v$ ($a \cdot u + b \cdot v = d$).
   - Нахождение обратного элемента: вход $(a, m) \to$ проверка обратимости, коэффициент Безу $u$ и наименьшее положительное $a^{-1} = u \bmod m$.
   - Решение сравнения $ax \equiv b \pmod m$: вход $(a, b, m) \to$ 1. Решений нет, 2. Одно решение, 3. Несколько решений.
   - Решение системы сравнений $(ax+y \equiv b, cx+y \equiv d \pmod m)$: вход $(a, b, c, d, m) \to$ 1. Решений нет, 2. Одно решение, 3. Много решений.
6. **Сменить алфавит** — переключение между русским и английским алфавитами.
0. **Выход**.
