# ОСНОВНАЯ ЧАСТЬ

## 1 Теоретические основы шифра Цезаря

Шифр Цезаря является классическим примером моноалфавитного шифра простой замены со сдвигом. Каждому символу открытого текста сопоставляется числовой индекс $x_i \in \{0, 1, \dots, m - 1\}$, где $m$ — мощность алфавита.

Преобразование шифрования определяется формулой циклического сдвига:

$$y_i = E_k(x_i) = (x_i + k) \pmod m$$

где $k \in \{1, 2, \dots, m - 1\}$ — секретный ключ шифрования.

Расшифрование осуществляется обратным сдвигом на величину ключа $k$:

$$x_i = D_k(y_i) = (y_i - k) \pmod m$$

В соответствии с методическими указаниями для текстов на русском языке применяется алфавит мощностью $m = 32$, в котором буквы «е» и «ё» отождествляются и имеют единый числовой код 5. Кодирование символов приведено в таблице.

## 2 Методика криптоанализа методом полного перебора

Главным недостатком шифра Цезаря является крайне малый объем пространства ключей: для алфавита мощности $m$ существует всего $m - 1$ нетривиальных ключей. Для русского алфавита ($m = 32$) число возможных ключей составляет 31.

Атака на основе только шифр-текста (ciphertext-only attack) осуществляется тривиальным перебором всех значений $k \in \{1, 2, \dots, 31\}$. Для каждого значения вычисляется предполагаемый открытый текст, после чего аналитик визуально или программно идентифицирует осмысленное русское предложение.

## 4 Листинги ключевых фрагментов программы

Ниже приведены основные функции реализации шифра Цезаря.

Листинг: Реализация прямого и обратного преобразования шифра Цезаря

```python
def E_k(x: int, k: int, m: int = 32) -> int:
    """Прямое преобразование: y = (x + k) mod m."""
    return (x + k) % m


def D_k(y: int, k: int, m: int = 32) -> int:
    """Обратное преобразование: x = (y - k) mod m."""
    return (y - k) % m


def encrypt_text(text: str, k: int, char_to_code: dict, code_to_char: dict, m: int = 32) -> str:
    """Посимвольное шифрование текста."""
    result = []
    for ch in text.lower():
        norm_ch = 'е' if ch == 'ё' else ch
        if norm_ch in char_to_code:
            code_y = E_k(char_to_code[norm_ch], k, m)
            result.append(code_to_char[code_y])
        else:
            result.append(ch)
    return ''.join(result)


def decrypt_text(text: str, k: int, char_to_code: dict, code_to_char: dict, m: int = 32) -> str:
    """Посимвольное расшифрование текста."""
    return encrypt_text(text, -k, char_to_code, code_to_char, m)


def brute_force(ciphertext: str, char_to_code: dict, code_to_char: dict, m: int = 32) -> list[tuple[int, str]]:
    """Полный перебор всех возможных ключей k в кольце Z_m."""
    return [(k, decrypt_text(ciphertext, k, char_to_code, code_to_char, m)) for k in range(1, m)]
```
