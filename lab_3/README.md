# ЛР3 — Модель открытого текста

Требования: методичка, с. 24–25; вариант 16, с. 28; отчёт, приложение 3, с. 52.

Из корня `MOZI`:

```powershell
python -m pip install -r requirements.txt
python -m lab_3.main
python -m lab_3.main --file lab_3/texts/variant_16.txt
python -m lab_3.main --file example.txt --language en --output lab_3/outputs/english
python -m lab_3.tui --file lab_3/texts/variant_16.txt
python -m pytest -q
```

При обычном запуске `python -m lab_3.main` открывается экранный TUI. На вкладке
«Текст» вставьте текст в большое многострочное поле, укажите путь к файлу и
нажмите «Загрузить файл» либо нажмите «Открыть вариант 16». Выберите язык в
списке и нажмите «Посчитать» (также работает `Ctrl+Enter`). Программа
автоматически откроет вкладку «Результаты»: линия Hk/k с точками и подписями
осей видна на вкладке «График Hk/k». `Ctrl+O` открывает PNG matplotlib
в просмотрщике изображений. Свернутая секция «Обработанный текст» показывает полную очищенную строку
при раскрытии. На вкладке «Частоты k-грамм» выберите k,
чтобы просматривать прокручиваемую таблицу частот. `Ctrl+Q` закрывает
приложение. Папку для сохранения результатов и графика можно задать в поле
«Папка для отчёта и результатов» (по умолчанию `outputs/`). Каждый расчёт
архивируется в отдельной подпапке с датой и временем; копии последнего
результата остаются в выбранной папке.

Вариант пакетного запуска с аргументом `--file` сохраняет анализ без TUI.
Русский алфавит соответствует
ЛР2: 32 буквы, ё → е. Регистр игнорируется, чужие буквы и все остальные
символы удаляются, текст склеивается без разделителей.

Используются перекрывающиеся окна со сдвигом 1; для k имеется N−k+1 окон.
В TUI частоты показаны в таблице по выбранному k; пакетный режим выводит
полный список в консоль. Результаты сохраняются в папке каждого расчёта: `input.txt`, `prepared.txt`,
`frequencies.csv`, `entropy.csv`, `analysis.txt`, `entropy.png`. В выбранной
папке также остаются копии файлов последнего расчёта. При N<k значение
отсутствует; очищенная пустая строка вызывает ошибку. Старые папки расчётов
не перезаписываются.

## Отчёт

`report.md` и `report.docx` содержат вариант 16 — «Парус» Лермонтова,
метаданные студента из ЛР2, формулы, фактические таблицы, график и код.
H5/5 оценивается отдельно от асимптотической энтропии языка: для 158 букв
достоверно установить предел невозможно.

Пересчитать исходный Markdown и рисунок:

```powershell
python -m lab_3.build_report
```

Сконвертировать каноническим проектом `md-to-docx` из его корня:

```powershell
python -m md2docx C:/projects/MOZI/lab_3/report.md --config configs/fit-academic.json -o C:/projects/MOZI/lab_3/report.docx
```

Конвертер и его зависимости устанавливаются отдельно. Файл с исходным
текстом содержит только фрагмент задания, без подписи автора.
